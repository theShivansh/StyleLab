# PHASE 1 — Foundation

Act as a staff-level repository architect.

Build the project foundation for STYLELAB.

Tasks:
- inspect current repo
- establish or preserve Next.js/TypeScript/Tailwind conventions
- add strict types
- create design tokens
- create folder boundaries
- establish API client abstraction
- establish feature flags/config
- create demo data layer
- create provider adapter interfaces
- establish error/loading conventions
- establish accessibility utilities
- create baseline tests
- add `.env.example`
- add/update README

Do not build major product screens yet.

Acceptance:
- app runs
- production build succeeds
- typecheck succeeds
- lint succeeds
- test suite is configured
- architecture boundaries are obvious
