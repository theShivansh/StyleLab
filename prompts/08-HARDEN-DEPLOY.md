# FINAL PHASE — Harden, Verify, Deploy

Act as release manager + senior QA + product reviewer.

Run:
- formatting
- lint
- typecheck
- unit tests
- integration tests
- production build

Audit:
- responsive breakpoints
- accessibility
- reduced motion
- loading/error/empty states
- image performance
- AI fallback behavior
- privacy copy
- secret exposure
- API ownership checks
- analytics completeness

Then perform a visual audit of:
- landing
- composer
- generation
- result
- remix
- planner

Fix issues found.

Finally update:
- README
- docs/ARCHITECTURE.md if needed
- `.env.example`
- deployment instructions
- known limitations
- demo script

Acceptance:
A recruiter can open the app, use demo mode, understand the value, experience compose→visualize→remix, and reach a polished result without needing a private retailer account.
