# Plan Build

Read the project instructions and relevant product docs.

1. Inspect the repository.
2. Identify the smallest architecture-consistent implementation.
3. Break the request into independently verifiable tasks.
4. Identify dependencies and risks.
5. Identify files likely to change.
6. Decide what should be delegated to specialist agents.
7. Write/update `docs/PLAN.md`.
8. Do not implement until the plan is internally consistent.

Return:
- product goal
- technical approach
- task graph
- verification gates
- assumptions
