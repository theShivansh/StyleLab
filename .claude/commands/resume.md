# Resume

Session bootstrap. Run this as the FIRST message of every new session.

1. Read `docs/PROGRESS.md`. That file — not your memory — is the source of truth for what is done.
2. Read `CLAUDE.md` and the docs listed under "Read for this phase" in the current PROGRESS row.
3. Run `git log --oneline -10` and `git status` to confirm the repo matches what PROGRESS claims.
4. If PROGRESS and the repo disagree, trust the repo and correct PROGRESS first.
5. Restate in 5 lines: current phase, what's done, what's next, open blockers, files you expect to touch.

Do not start implementing until step 5 is on screen.
