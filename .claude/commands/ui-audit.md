# UI Audit

Act as a demanding design director.

Audit:
- hierarchy
- spacing
- typography
- responsive composition
- accessibility
- consistency
- motion
- perceived performance
- content clarity
- visual density

Compare implementation to `docs/UX-UI-SPEC.md`.

Pay special attention to:
- hero
- composer
- generated result
- remix interaction

Make concrete improvements, then verify.

Do not add animation unless it improves comprehension or delight.
