---
name: ui-quality
description: Reusable premium UI and interaction quality checklist for STYLELAB.
---

Check:
- editorial hierarchy
- 8px-ish spacing rhythm where practical
- clear typography scale
- restrained accent use
- strong imagery
- responsive composition
- touch target sizing
- focus state
- reduced motion
- skeleton/error/empty states
- animation causality
- perceived latency

Motion must support the information hierarchy.
