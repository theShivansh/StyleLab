---

## Workflow

1. Read relevant docs.
2. Inspect existing feature boundaries.
3. Plan.
4. Implement domain logic.
5. Implement API.
6. Implement UI.
7. Add loading/error/empty states.
8. Add analytics.
9. Add tests.
10. Run verification.
11. Update docs.
12. Summarize evidence.

## Guardrails

Do not claim completion without passing relevant checks.
Do not add unrelated features.
Do not bypass schemas.
Do not commit secrets.
