# STYLELAB Design Prompt System

These prompts are intended for image/design-generation models and for Claude Code/Codex when translating references into UI.

## Design north star

> Editorial fashion × AI laboratory × premium commerce.

Never copy another brand's exact UI. Use broad visual inspiration only.

## Global art direction prompt

Create a premium fashion-commerce interface for STYLELAB ✦, an AI outfit composer. Warm ivory background #FAF9F7, near-black typography, restrained pink accent #FF3F7F, high-fashion editorial imagery, sophisticated spacing, oversized typography, 20–28px rounded cards, subtle glass surfaces, soft neutral shadows, realistic product photography, quiet luxury, modern AI product feel. Avoid generic SaaS gradients, neon-heavy cyberpunk, crypto aesthetics, excessive glassmorphism, clutter, or template-like dashboards. High-end product design, polished responsive composition, realistic UI hierarchy.

## Landing hero prompt

Create a 16:9 premium desktop landing page for STYLELAB ✦. Headline: “YOUR WARDROBE. RECOMPOSED.” Subheadline: “See the outfit before you buy it.” Large editorial fashion visual dominates the hero. Floating product cards subtly orbit the visual. Primary CTA: “✦ Compose my look”. Secondary action: “Explore demo”. Show subtle AI intelligence markers without making the page look like a developer tool. Warm ivory canvas, black type, pink accent, glass micro-cards, soft shadows, large typography, luxury editorial composition.

## Composer prompt

Design the primary STYLELAB AI Outfit Composer desktop interface. Large user preview on the left, AI style summary and selected products on the right. Bottom or side product tray with top, bottom, shoes, and layer. Primary CTA “✦ Compose outfit”. Show selected states clearly. Make the experience tactile and fashion-editorial rather than a form builder. Use warm ivory, black, pink accent and quiet glass surfaces.

## Result prompt

Create STYLELAB result screen after AI generation. Centerpiece is a full-body fashion visualization. Above/beside it: “YOUR LOOK”, outfit name, “94 STYLE MATCH” presented as a UX heuristic, and concise reasons. Below: known catalogue products with prices and shopping actions. Primary action: “Remix”. Secondary actions: Save, Share, Shop look. Make the image reveal feel cinematic but keep controls obvious.

## Remix prompt

Create a “WHAT IF?” remix experience for STYLELAB. The current generated look stays visible while a bottom sheet or side rail exposes alternative garments. Tabs: Top, Bottom, Shoes, Layer. Each option uses a clean product card. Selecting an alternative should visually imply a single-parameter transformation, not a complete restart. Premium motion, elegant spacing, restrained accent usage.

## Planner prompt

Create a 7-day STYLELAB wardrobe planner. Seven editorial cards, each with an occasion label, generated look image, short style title, and actions to open, save, remix, or shop. Use varied layouts but consistent components. Avoid calendar-app aesthetics.

## Mobile prompt

Create the mobile version of STYLELAB. Prioritize one-hand interaction. Large visual preview, bottom sheets for product selection, sticky action controls, compact style summary, clear primary CTA. Use bottom navigation only when truly needed. No desktop UI shrunk into mobile.

## AI generation prompt

Create a premium cinematic AI-generation state for STYLELAB. Progress sequence:
“Reading your style”
“Matching silhouettes”
“Building outfit”
“Rendering your look”
“Almost ready”
Use subtle shimmer, editorial image placeholder, progressive reveal, and motion that communicates causality. Avoid a generic circular loader.

## Share-card prompt

Create a social-friendly STYLELAB look card. Large generated outfit image, style title, Style Match, small product chips, “Shop this look” CTA, STYLELAB ✦ signature. Minimal, vertical-first, high-fashion editorial feel.

## Negative prompt

Do not produce:
- fake logos
- retailer-specific branding
- crowded dashboards
- excessive neon
- crypto/web3 visuals
- random charts on hero screens
- unreadable microtext
- fake product prices presented as real
- unrealistic body-analysis claims
- giant AI chatbots as the main interface
- low-contrast controls
- decorative UI without function
