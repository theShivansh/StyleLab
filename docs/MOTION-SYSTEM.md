# Motion System

## Principles

Motion must explain:
- hierarchy
- state
- cause/effect
- spatial relationships

## Timing

Functional:
100–180ms

Spatial:
250–500ms

Hero:
600–1200ms

## Signature transitions

### Compose
Selected garments settle into their slots.

### Generate
Progress states crossfade.

### Reveal
Generated image moves from blurred placeholder to sharp final state.

### Remix
Only the changed garment area gets a strong transition while unchanged product cards remain stable.

## Reduced motion

When `prefers-reduced-motion: reduce`:
- remove parallax
- remove image trails
- reduce transform distance
- remove non-essential animated backgrounds
- keep essential state transitions understandable
